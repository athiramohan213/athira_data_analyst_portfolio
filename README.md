How to Run Locally

Download or clone this repository.

Open the project folder in Visual Studio Code.

Open index.html in a browser, or use the VS Code Live Server extension.

##Deployment

This static website can be hosted using GitHub Pages.

Upload the website files to a GitHub repository.

Open Settings → Pages.

Under the publishing source, choose Deploy from a branch.

Select the main branch and the / (root) folder, provided index.html is in the repository root.

Save the settings and wait for deployment.

The live portfolio link can be added here after successful deployment.

Browser Compatibility

Designed for modern browsers. Compatibility should be verified by testing the website in the browsers you intend to support.
